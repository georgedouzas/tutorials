## Conventions used in this tutorial

Page abbreviations as in the Meaning column (CM classical-mechanics, EM electromagnetism, SR special-relativity, TSM thermodynamics-statistical-mechanics, QM quantum-mechanics, CFT classical-field-theory, Dirac dirac-equation, QFT quantum-field-theory, GT gauge-theories, Ren renormalisation, GR general-relativity, SUSY supersymmetry-supergravity). Line numbers refer to `<page>/index.qmd`.

- **Metric signature: (+, -, -, -) in every formula of every page.** It is stated at SR:47-49, CFT:21, Dirac:32, QFT:1959, Ren:48-49, GR:22, 52-53, SUSY:27-31, 4410, GT:560, 1166, and in every Sage cell that builds eta (e.g. CFT:2987, GT:4872, SUSY:606). Higher dimensions use (+, -, ..., -) with a negative-definite internal metric g_mn = -gamma_mn (GR:1599, SUSY:4410, 6591, 6731), as on the Kaluza-Klein conventions page. Every mention of (-, +, +, +) / "mostly plus" is a comparison that names the source and converts:
  - SR:49 (Maggiore, Bekaert-Boulanger; rule eta -> -eta);
  - GR:35, 662-666, 969, 1227, 1438, 4795, 5818 (Carroll; GR:5818 contrasts the sign of h_xx);
  - SUSY:30-31, 51, 272-273, 625-649 (Martin, Nath), 877-878, 952, 1525, 1580, 1948, 2777, 2973, 6331-6340 (Duff), 6730-6735 (Duff);
  - Dirac:202-216 (exercise translating Zhelnorovich's g = diag(1, 1, 1, -1) into ours);
  - GT:6768 (Proca mass term "in the mostly-plus signature": the only comparison that does not name whose convention it is);
  - QFT:3881 (diag(-1, 1, 1, 1) is -eta in a projector computation, not a signature) and SR:3255 (time-reversal matrix T = diag(-1, 1, 1, 1)) are false positives.
  No passage uses the mostly-plus signature in its own formulas.
- **Curvature:** R^rho_{sigma mu nu} = d_mu Gamma^rho_{nu sigma} - ..., R_{mu nu} = R^rho_{mu rho nu}, the scalar R flips sign relative to Carroll (GR:35-38, 662), S_EH = -(1/2kappa^2) int sqrt(-g) R with kappa^2 = 8 pi G (GR:658), G_{mu nu} = kappa^2 T_{mu nu} (GR:1119). SUSY uses -1/4 e R with 4 pi G = 1 (SUSY:5374, 6314). Same as the Kaluza-Klein conventions page. de Sitter has R_{mu nu} = -3H^2 g (GR:1942), AdS a positive multiple (SUSY:6731).
- **Fourier and plane waves:** positive-frequency modes e^{-ik.x} with k.x = omega t - k.x (QFT:996-998, Dirac), plane waves e^{i(k.x - omega t)} (EM:8895, QM), which is the same sign. Momentum space: QM uses the unitary (2 pi hbar)^{-1/2} int e^{-ipx/hbar} (QM:209-210, citing the maths def-fourier-transform, which is non-unitary hat f(k) = int f e^{-ikx}); QFT puts (2 pi)^4 in the inverse transform, int d^4k/(2pi)^4 e^{-ik.x} (QFT:3537), and (2 pi)^3 delta^3 in the commutator (QFT:999). Consistent within each chapter; the symbol for the transform varies (clash 9).
- **Units:** Heaviside-Lorentz with c = 1, SI where numbers are given (EM:39, 4975, SR:37, 47, 8569, QM:7651, QFT:3129, GR:3866); hbar explicit in CM, EM, QM (plots hbar = m = 1, QM:25); hbar = c = 1 in Dirac:32, QFT (from the second section, QFT:22, 840), Ren:48, GT (3626), SUSY; k_B = 1 throughout TSM (TSM:26) and hbar = 1 there where quantum mechanics enters; GR keeps G explicit with c = 1 (GR:658, 715). Gaussian units appear only as comparisons (GT:3688, GR:3866).
- **Inner product:** antilinear in the first slot (QM:54), matching the maths tutorial; no other page states one.
- **Vectors:** arrows \vec in CM, SR, QM, CFT, Dirac, QFT, GT, GR, SUSY; bold \mathbf / \boldsymbol in EM (3922 + 126) and TSM (68), plus stray bold A, E, B in SR:8565, QM, GR (clash 1). Bold is otherwise used for representation labels \mathbf 3, \mathbf{10} (GT, SUSY).
- **Expectation:** <A> = <psi, A psi> for quantum expectation values and <.>_beta for thermal averages (QM, TSM, QFT, GT); \mathbb E only for classical random variables (QFT:4224, 4442, TSM:5063-5155). No conflict with the site default \mathbb E, but <.> should be recorded as the physics notation.
- **Lie-algebra generators:** GT follows the Kaluza-Klein page: anti-Hermitian T_a, [T_a, T_b] = f_ab^c T_c, Tr(T_a T_b) = -1/2 delta_ab (GT:781, 1176, 5835, 8165, 13521), D_mu = d_mu + A_mu, with Hermitian partners written t_a = i T_a (GT:1457, 1580, 5861). SUSY (3572-3874) and Ren (4178) use Hermitian generators written T^a = sigma^a/2 with tr(T^a T^b) = T(R) delta (clash 3).
- **U(1) coupling:** D_mu = d_mu + i q A_mu everywhere (Dirac:2014, QFT:2416, 5780, GT:22, Ren:3305), electron q = -e (QFT:2416); GT:1458 writes D = d - i g \mathcal A^a t_a as the sources' dictionary (comparison).
- **Levi-Civita orientation:** not uniform (clash 2).
